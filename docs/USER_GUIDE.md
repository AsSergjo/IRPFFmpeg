# Руководство пользователя

## Запуск

Запускайте приложение через:

```text
Start_IRPFFmpeg.exe
```

Загрузчик проверит наличие `IRPFFmpeg.exe`, создаст папку `heap_dll` при необходимости, перенесет DLL из корня релизной папки в `heap_dll`, добавит эту папку во временный путь поиска библиотек и запустит основное приложение.

## Плейлист

Основной список станций хранится в `playlist.m3u`. Его можно редактировать вручную или менять из интерфейса приложения.

В контекстном меню списка станций можно добавить станцию, изменить ее название, сохранить текущее отображаемое название в `playlist.m3u` или удалить станцию. Заданное пользователем название станции сохраняется при обновлении ICY metadata потока.

Поддерживаемые URL обычно начинаются с:

```text
http://
https://
icy://
mms://
rtsp://
```

Пример M3U:

```text
#EXTM3U
#EXTINF:-1,Example Radio
https://example.com/stream
```

## Воспроизведение

Приложение умеет:

- запускать и останавливать поток;
- переключаться между станциями;
- возвращаться к предыдущей станции;
- показывать текущий трек, если станция передает метаданные;
- сохранять заданное пользователем название станции при обновлении метаданных;
- показывать технический статус потока;
- сохранять состояние между запусками.

Если станция не отвечает или поток временно недоступен, приложение пытается переподключиться.

Если сервер присылает битые аудиоданные, приложение может временно показать статус `Пропускаем битые данные от сервера...`. В этом состоянии оно пропускает некорректные фреймы и ждет восстановления стабильного потока.

## Обложки

IRPFFmpeg пытается найти обложку текущего трека, загрузить ее и сохранить в `cover_cache`. Кэш нужен, чтобы не скачивать одно и то же изображение повторно.

Если обложка недоступна, воспроизведение продолжится без нее.

## Запись эфира

Записи сохраняются в папку `Rec`.

Доступны форматы:

- MP3 320 kbit/sec;
- FLAC 16-bit.

Имя файла формируется из текущего трека, если поток передает корректные метаданные. Недопустимые для Windows символы удаляются или заменяются.

Если обложка и метаданные доступны, приложение пытается добавить их в записанный файл.

## Звук

Доступные настройки:

- язык интерфейса;
- громкость через дуговой контрол в главном окне;
- шестиполосный параметрический эквалайзер `30 / 200 / 2000 / 5000 / 10000 / 16000 Hz`;
- Stereo Width;
- Exciter;
- DeepBass;
- компрессор разборчивости речи;
- LUFS-нормализация станций;
- GainRider;
- финальный лимитер.

Левый клик по контролу громкости увеличивает уровень, правый уменьшает; также поддерживаются колесо мыши и клавиши со стрелками. Кнопка эквалайзера открывает отдельное окно, где для каждой из шести полос есть большой регулятор усиления, малый регулятор добротности `Q` и живой график суммарной АЧХ. Компрессор разборчивости речи поднимает тихие фразы и мягко сжимает громкие места, чтобы речь не терялась на станциях с большим динамическим разбросом. GainRider после всех фильтров контролирует активность финального лимитера и уменьшает общий уровень, когда лимитер начинает слишком сильно сжимать сигнал. LUFS-нормализация станций хранит 120-секундную историю потока и приводит его к ориентиру `-9.00 LUFS`; отдельный быстрый аудиоконтур снимает оставшееся усиление при резком росте громкости, не сбрасывая историю и не используя metadata. Stereo Width, Exciter и DeepBass лучше использовать умеренно: слишком большие значения могут сделать звук менее естественным.

Язык интерфейса можно выбрать в настройках. Файлы локализации лежат в папке `Language` рядом с exe, а выбранный язык сохраняется между запусками в `app.dat`.

## Системный трей

Приложение может сворачиваться в системный трей. Это удобно, если радио должно продолжать играть в фоне.

Если включена настройка показа обложки при смене трека, во время работы из трея или компактного режима приложение показывает небольшое всплывающее окно с текущей обложкой и названием композиции. Окно можно перетащить в удобное место; позиция сохраняется между запусками.

## Компактный режим

Компактный режим включается двойным щелчком по области обложки. В этом режиме окно становится небольшим: сверху остается спектральная визуализация, снизу - строка текущего трека и две кнопки.

Кнопки компактного режима:

- возврат к ранее звучавшей станции;
- возврат в обычный режим.

Слева в нижней строке закреплено время, прошедшее с начала текущего сеанса воспроизведения. Длинные названия треков плавно прокручиваются независимо от счётчика времени. Окно можно перетаскивать мышью за спектр или нижнюю строку. При возврате в обычный режим позиция компактного окна сохраняется в `app.dat`; при следующем включении компактное окно появляется на сохранённом месте. Двойной щелчок по строке трека также возвращает обычный режим.

В настройках можно включить или отключить режим `Компактный режим поверх всех окон`. Если он включен, компактное окно остается поверх других окон; при выходе из компактного режима обычное окно возвращается к нормальному поведению.

Настройка `Без спектрограммы в компактном режиме` сокращает окно до нижней строки с названием трека и кнопками. Пока этот режим активен, данные не подаются в ShowCQT и визуализация не рендерится; при возврате в обычное окно спектрограмма запускается автоматически с нового аудиобуфера.

## Если приложение не запускается

Проверьте:

1. Запускается именно `Start_IRPFFmpeg.exe`.
2. Рядом есть `IRPFFmpeg.exe`.
3. Рядом есть папка `heap_dll`.
4. В `heap_dll` лежат FFmpeg, SDL2 и сопутствующие DLL.
5. Папка приложения доступна на запись, если нужны настройки, записи и кэш обложек.
